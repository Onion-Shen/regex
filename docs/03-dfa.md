# 03 · 子集构造与 DFA 最小化

对应源码：`src/dfa.ts`。

## 1. 为什么要 DFA

NFA 匹配要同时维护一组状态；DFA 在任意时刻只有一个状态，转移是确定的：

```
next = δ(current, class(input))
```

代价是状态数可能指数增长。子集构造就是把「一组 NFA 状态」打包成一个 DFA 状态。

## 2. 字母表等价类

DFA 的转移表不应以 110 万个码点为列。做法是：收集 NFA 中所有字符集的所有区间端点，切成若干段；如果两段在所有字符集中的「属于/不属于」签名完全一致，它们就可以合并成一个等价类。

```
边界点: 0, 'a', 'b', 0x110000
类:     [0, 'a'-1]     签名 000
        ['a', 'a']     签名 010
        ['b', 'b']     签名 001
```

`buildAlphabet` 还会为每个类保留一个代表码点（区间下界），子集构造和运行时分类都只需比较代表码点。`CharClass.set` 则保存完整区间，供输出表格/DOT 使用。

## 3. 子集构造

```ts
start = ε-closure({nfa.start})

for each unvisited subset S:
  for each class c:
    T = { edge.to | s ∈ S, s --charset(c)--> edge.to }
    if T 为空: δ(S, c) = -1        // 死状态
    else:      δ(S, c) = intern(ε-closure(T))
```

要点：

- 子集用状态 id 排序后拼接成 key，便于去重；
- `ε-closure` 必须用 visited 集合，NFA 允许 ε 环；
- 接受状态：子集中只要有一个 NFA 接受状态，DFA 状态就是接受状态；
- `-1` 不是实际状态，表示死转移；很多实现会显式加一个死状态，这里选择省略列。

### 例：`(a|b)*abb`

原始子集构造得到 **5 个状态**，而不是教科书上的 4 个。原因在 Thompson 构造：起点 ε 闭包是 `{q6, q0, q7, q8, q2, q4}`，而读入一个 `b` 后的集合多出 `q1, q5`，两者 NFA 集合不同，因此是不同 DFA 状态。

它们的行为其实完全一致（非接受，`a` 去同一状态，`b` 去同一状态），所以最小化会合并成经典的 4 状态 DFA。这个差异正好说明「子集构造」和「最小化」是两件事。

```
状态   接受  \0-`…  [a]  [b]
 S0            —     S1   S2
 S1            —     S1   S3
 S2            —     S1   S2
 S3            —     S1   S4
→S4      ✓     —     S1   S2
```

最小化后：

```
状态   接受  \0-`…  [a]  [b]
 S0            —     S1   S0
 S1            —     S1   S2
 S2            —     S1   S3
→S3      ✓     —     S1   S0
```

## 4. Moore 分区细化最小化

目标：把行为等价的状态合并。

1. 初始划分：接受状态一组、非接受状态一组。
2. 反复细化：对每个状态计算签名

   ```
   当前块号 | 是否接受 | 每个字母类转移到的块号
   ```

   签名相同的状态进入同一新块。
3. 当块的数量不再增加时停止。

签名里必须包含「当前块号」，否则只比较转移目标会丢失区分信息。

最后为每个块建一个新状态，块内任选代表状态复制转移，并把目标映射到目标块号。

## 5. 锚点与 DFA

`^` / `$` 是否成立取决于**当前位置**，而 DFA 状态不携带位置信息。因此 `determinize` 在检测到 `nfa.hasAssertions` 时直接抛 `RegexCompileError`，而不是悄悄给出错误结果。

`Regex` 默认用 NFA 匹配，`toDFA()` 主要用于学习、检查语言和整串判定。

## 6. 输出与可视化

- `dfa.toTable()`：ASCII 状态转移表，`→` 标记接受状态，`—` 表示死转移。
- `dfa.toDot()`：Graphviz DOT，可粘贴到在线渲染器或本地 `dot`。
- `regex.toDFA(true)`：返回最小化结果，结果会被缓存。

## 7. 复杂度

- 子集构造最坏 `O(2^n)` 个状态；
- 最小化采用朴素分区细化，约为 `O(状态数² × 字母类数)`，教学场景足够；
- 字母表等价类数量不超过 `2 × 区间数 + 1`。
