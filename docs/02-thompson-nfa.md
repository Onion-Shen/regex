# 02 · Thompson 构造：AST → NFA

对应源码：`src/nfa.ts`。

## 1. 目标

把任意正则 AST 变成一个 **NFA**（非确定有限自动机）：

- 状态之间有三种边：`ε`（不消耗输入）、字符集（消耗一个匹配的码点）、断言（零宽）；
- 只有一个起点和一个接受点；
- 每个 AST 节点构造出一个「片段」（fragment），片段有各自的入口和出口，再按规则拼接。

NFA 是后续一切的基础：集合模拟直接跑它，子集构造再把确定性买回来。

## 2. 基本片段

空串和单字符：

```
ε:  s ──ε──▶ f

a:  s ──[a]──▶ f
```

代码里每个片段都是：

```ts
interface Fragment {
  start: NfaState;
  accept: NfaState;
}
```

## 3. 连接（concat）

`AB`：把 A 的出口用 ε 边连到 B 的入口。

```
A.start ... A.accept ──ε──▶ B.start ... B.accept
```

多个子节点从左到右折叠；空列表退化为一个 ε 片段。连接不会创建新的中间状态，只在片段之间加 ε 边。

## 4. 选择（alt）

`A|B|C`：新建统一的起点和终点。

```
        ε ──▶ A ── ε
start ─ ε ──▶ B ── ε ─▶ accept
        ε ──▶ C ── ε
```

每个分支的出口都指向同一个 accept，因此 NFA 天然支持「猜哪条分支」。

## 5. 闭包（star / plus / question）

`A*`：

```
start ──ε──▶ A.start ... A.accept ──ε──▶ accept
  │                          │
  └──────────ε───────────────┘（跳过循环）
              └──ε──▶ A.start（再来一轮）
```

关键点：`A.accept` 同时连回 `A.start` 和 `accept`。前者形成**ε 环**，后者允许退出。

`A+` 复用这个构造：先放一份必须的 `A`，再接一个 `A*`。
`A?` 用嵌套可选项构造：`start` 分别 ε 到「A 的片段」和「直接接受」。

## 6. 有界重复 `{n,m}`

`buildRepeat` 分三段：

1. 先构造 `n` 份必需副本；
2. 若 `m = null`（即 `{n,}`），追加一个 `A*`；
3. 若 `m > n`，追加 `m - n` 层嵌套可选：

```
(A (A (A)?)?)?
```

可选链**从内向外**构造，避免递归深度随 `m` 线性增长。所有量词展开都有上限：

- `maxRepeat`（默认 1000）：`{n,m}` 的 n/m 不得超过它；
- `maxStates`（默认 200000）：NFA 状态总数上限。

超过上限抛 `RegexCompileError`，这是对 `a{999999}` 这类输入的必要防护。

## 7. 断言边

`^` / `$` 不消耗输入，但也不像 ε 那样无条件通过：

```ts
{ kind: 'assert'; assertion: 'start' | 'end'; to: NfaState }
```

断言是否成立依赖**当前输入位置**，所以只能在匹配阶段（`matcher.ts`）判断。NFA 只知道「这里有一个零宽条件」。

## 8. 为什么必须处理 ε 环

`(a*)*`、`(a|ε)*` 等表达式会产生「只走 ε 边就能回到自己」的环。任何遍历 ε 闭包的代码都必须记录 `visited`，否则会无限递归。

本实现中：

- 子集构造的 `epsilonClosure` 用 `Set` 去重；
- 匹配器的 `closure` 用 `Map<state, start>`，并在「已有更早起点」时剪枝。

## 9. 例子：`(a|b)*abb`

Thompson 构造得到 14 个状态（编号取决于构造顺序）：

```
q6 ─ε→ q0, q7
q0 ─ε→ q2, q4          // (a|b) 的分支
q2 ─[a]→ q3 ─ε→ q1
q4 ─[b]→ q5 ─ε→ q1
q1 ─ε→ q0, q7          // 回到循环或退出
q7 ─ε→ q8 ─[a]→ q9 ─ε→ q10 ─[b]→ q11 ─ε→ q12 ─[b]→ q13(accept)
```

`q1` 的两条 ε 出边正是「循环」和「退出」的来源。用 `npm run cli -- debug '(a|b)*abb'` 可以看到实际编号。

## 10. 复杂度

NFA 状态数与 AST 大小线性相关（忽略量词展开）。匹配时每读一个码点，需要遍历当前活动状态集合及其 ε 闭包，最坏 `O(状态数 × 输入长度)`，但不需要回溯，也不会指数爆炸。
